# A per-run Talent Tree, separate from Legacy

The player has one Talent Tree shared by all Settlements, bought with Talent Points earned from Renown. Talents reset on Prestige (as does the respec counter). We rejected making Talents permanent, or folding them into Legacy, because that leaves Legacy with no job: Talents shape the current run, Legacy is the only layer that carries over.

Talent bonuses add together, and the total multiplies with Trait and Specialization bonuses (five +3% speed Talents give ×1.15, then × Green Thumb). We rejected multiplying every bonus because it compounds out of control as the web grows and can't be summed in a tooltip. Changing either rule later means rebalancing every node.
